# ADHD Productivity Panel — Habits Shell Rollout Iteration 01

## Recommendations

1. Keep the top action obvious: one persistent `New Habit` entry point in the shell plus one inline action in the library section.
2. Remove fake checkbox affordances for template checklists; show them as read-only structure instead of interactive controls that do nothing.
3. Keep the page segmented into a small number of clear jobs: orient, read the rhythm, manage the library, then hand off to the next view.
4. Record the next rollout order explicitly so follow-up work does not get lost once the habits page is done.

## Accepted

All four recommendations were accepted for the shipped habits shell.
