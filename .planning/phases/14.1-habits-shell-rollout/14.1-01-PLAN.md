# Phase 14.1 Plan 01: Habits Shell Delivery

## Objective

Ship the mature section-shell pattern on `/habits`, replace the legacy inline page script with a lifecycle-safe controller path, and preserve all habit CRUD flows.

## Tasks

1. Define a canonical habits section registry for unified-bar tabs and title switching.
2. Recompose `habits.astro` around server-rendered routine data, hash-linked shell sections, and a custom create-habit action in `UnifiedBar`.
3. Extract the inline habits behavior into `habits-controller.ts` and align all listeners with `pageLifecycle`.
4. Preserve create, edit, delete, complete, checklist, streak, and SearchHub handoff behavior after the shell migration.
5. Add focused browser coverage and document the next rollout order.

## Must Haves

1. No new habits-specific search surface or API endpoint.
2. No regression in `/api/habits` create, update, delete, or complete flows.
3. Initial page load stays Astro-first and works behind Home Assistant ingress.
4. Verification is explicit about Tier 1 and the reason Tier 2 is not required.
