# Phase 14.6 Context: Kanban Shell Rollout

## Domain Boundary

This phase applies the unified shell to `/kanban` without flattening board-first controls, lane management, or route-switch context.

## Decisions

1. Keep `TaskViewTabs` beneath the shell.
2. Keep `Manage Lanes` as a shell action.
3. Move field emphasis into the `kanban-fields` section instead of crowding the shell.
4. Normalize client fetches to bare `/api/...` paths so ingress path handling stays correct.
