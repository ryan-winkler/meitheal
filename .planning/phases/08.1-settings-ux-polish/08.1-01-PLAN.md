# Phase 08.1 Plan 01: Shell and Section UX

## Objective

Make the existing Settings redesign feel intentionally product-grade by clarifying shell roles, improving findability, and reducing repeated presentation patterns.

## Tasks

1. Extend `SettingsSectionDescriptor` with UI metadata for rail detail, section intro title/description, and common-task chips.
2. Create shared settings primitives for intros, cards, callouts, action rows, disclosures, and status chips.
3. Rework `settings.astro` so the summary strip is the persistent quick-jump/status surface and the mobile nav becomes a compact section picker.
4. Upgrade `settings-shell-controller.ts` search behavior with clearer results, arrow-key navigation, and reset handling.
5. Recompose Settings Personal, App/PWA, Danger Zone, and selected Workflow/Integrations surfaces around the new primitives.

## Must Haves

1. No API or persisted settings key changes.
2. No broken hash anchors or companion links.
3. No visual affordance that looks clickable without actually being clickable.
4. Search must help users jump, then get out of the way cleanly.
