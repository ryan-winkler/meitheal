This phase resets the shell rollout program for the remaining work surfaces. It captures the audit, locked decisions, requirements, and execution order, but does not redefine task-domain persistence or change route-level API contracts.

1. Treat this as a continuation of the existing shell rollout, not a new project bootstrap.
2. Use `UnifiedBar` as the primary shell on Today, Upcoming, Calendar, Kanban, and Table.
3. Keep `TaskViewTabs.astro` as the secondary route-switch strip on Calendar, Kanban, and Table.
4. Keep search on `SearchHub` and Assist on `ask-ha-btn`; do not introduce page-local alternatives.
5. Keep section navigation hash-based on the same route.
6. Ship in this order: Today, Upcoming, Calendar, Kanban, Table.
