# Phase 14.7 Context: Table Shell Rollout

## Domain Boundary

This phase applies the unified shell to `/table` without flattening filters, saved presets, column configuration, or row-detail handoff.

## Decisions

1. Keep `TaskViewTabs` beneath the shell.
2. Keep filters, presets, and fields in anchored sections below the shell.
3. Preserve row-click task-detail handoff through the shared task detail surface.
4. Keep `New Task`, SearchHub, and Assist in the shell action cluster.
