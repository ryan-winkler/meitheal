# Phase 12 Plan 02: Deferred Items D1 + D2

## Objective

Implement the two deferred items from Plan 01:
- **D1:** Auto-expand sidebar properties on mobile when task detail modal opens
- **D2:** Replace `window.location.reload()` in NewTaskModal with `meitheal:tasks-changed` CustomEvent + universal listener

## Context

- Sidebar toggle logic exists at `task-modal-controller.ts:73-81` (click handler on `#td-sidebar-toggle`)
- CSS: `td-sidebar-props` is `display:none` on mobile, `td-sidebar-expanded` shows it with animation
- `window.location.reload()` at `NewTaskModal.astro:446` after task creation
- `layout-controller.ts` runs on every page, ideal location for universal event listener

<name>D1: Auto-expand sidebar on mobile when task detail opens</name>
<files>
- apps/web/src/lib/task-modal-controller.ts (openTaskDetail function, ~line 83-101)

<action>
In `openTaskDetail()`, after setting `tdOverlay.classList.add("active")`, add mobile sidebar auto-expand:
```typescript
// D1: Auto-expand sidebar on mobile so properties are visible
if (window.matchMedia("(max-width: 767px)").matches) {
  _sidebarProps?.classList.add("td-sidebar-expanded")
  _sidebarToggle?.setAttribute("aria-expanded", "true")
  _sidebarChevron?.classList.toggle("td-chevron-open", true)
}
```
In `closeTD()` `finishClose()`, collapse sidebar back:
```typescript
// D1: Collapse sidebar on close (reset for next open)
_sidebarProps?.classList.remove("td-sidebar-expanded")
_sidebarToggle?.setAttribute("aria-expanded", "false")
_sidebarChevron?.classList.remove("td-chevron-open")
```
</action>

<task id="3" type="auto">
<name>D2: Add universal meitheal:tasks-changed listener in layout controller</name>
<files>
- apps/web/src/lib/layout-controller.ts
</files>
<action>
Add a listener at the end of the layout controller initialization:
```typescript
// D2: Universal task change listener — reloads page when tasks change
// This establishes the event pattern for future migration of reload() calls
// across kanban, today, table, and other controllers.
document.addEventListener("meitheal:tasks-changed", () => {
  window.location.reload()
})
```
This preserves the existing reload behavior (nothing changes for the user) while establishing the event bus pattern. Future phases can intercept this event in specific controllers to do targeted DOM updates instead of full reloads.
</action>
