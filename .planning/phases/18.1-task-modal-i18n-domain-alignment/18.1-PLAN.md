# Plan: Task Modal i18n, Domain Alignment & Feature Enrichment

**Phase:** 18.1 (gap-closure of Phase 18)

## Goal
Complete the New Task Modal overhaul: full i18n, domain-aligned TaskKind values, Templates removal, theme-friendly CSS, custom fields support, and AI handoff UI. Design validated via StitchMCP (project `16775713990343123215`, 5 screens).

## Data Model Reference
From `TaskResponse`:
- `custom_fields` (JSON string) — attachments, URLs, custom text/number/date/checkbox
- `framework_payload` (JSON string) — AI scoring, strategic metadata
- `handoff_state` (AI state machine: idle → claimed → proposed → accepted)
- `Owner` type: `"human" | "bot:${string}"` — AI attribution
- `parent_id` — native sub-item support (checklists)
- `start_date` / `end_date` — event datetime
- `labels` (JSON string) — tags
