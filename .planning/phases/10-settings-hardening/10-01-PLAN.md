  <action>
    For each controller:
    1. Add `import { pageLifecycle } from "@lib/page-lifecycle"` if not already imported
    2. Replace every `element.addEventListener("event", handler)` with `pageLifecycle.on(element, "event", handler)`
    3. For any `setTimeout()` calls, store the handle in a module-scoped variable and guard the callback:
       ```typescript
       const handle = setTimeout(() => {
         if (pageLifecycle.signal.aborted) return
         // original callback
       }, delay)
       ```
    4. DO NOT change the controller's function signatures or exports — this is a drop-in replacement

    Reference pattern from settings-shell-controller.ts:
    ```typescript
    pageLifecycle.on(button, "click", () => { /* handler */ })
    pageLifecycle.on(window, "hashchange", () => { /* handler */ })
    ```
  </action>
