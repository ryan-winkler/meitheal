# Phase 14 Plan 01: Shared Shell Pattern and Dashboard Delivery

## Objective

Ship the mature section-shell pattern on the dashboard using `UnifiedBar`, while formalizing the reusable interaction contract needed for habits and later pages.

## Tasks

1. Define a canonical dashboard section registry for the shell tabs and title switcher.
2. Add or extract reusable `UnifiedBar` interaction helpers needed outside Settings.
3. Recompose `index.astro` around hash-linked sections, a dashboard hero, and the new unified shell.
4. Update `dashboard-controller.ts` to boot safely through `pageLifecycle`, preserve quick add/task-detail actions, and manage dashboard shell navigation state.

## Must Haves

1. No dashboard data query or task API regression.
2. Search must keep using `SearchHub`, not a new page-local search implementation.
3. Section links must stay same-page and ingress-safe.
4. The new shell must remain Astro-native and not introduce component-owned SPA state.
