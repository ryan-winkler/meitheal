# Phase 09 Plan 01: Unified Search Hub

## Objective

Replace Meitheal's split topbar search and command palette with one modular search hub that supports advanced task search, navigation, settings, saved filters, and HA-aware actions.

## Tasks

1. Create the search domain and universal `/api/search` contract.
2. Add advanced task search in persistence for IDs, labels, custom fields, comments, completed/archive toggles, and relevance sorting.
3. Build a shared `SearchHub.astro` overlay plus a dedicated controller.
4. Rewire the topbar launcher and keyboard shortcuts to the new hub.
5. Update Home Assistant service, LLM, and MCP task search paths to reuse the upgraded behavior.
6. Restore canonical `docs/analysis/*` and add a KCS touchpoint for search behavior.
7. Add browser/API verification for launch, navigation, and universal-result behavior.

## Must Haves

1. One visible launcher, one keyboard launcher, one search surface.
2. Search works behind ingress.
3. Task results open task detail directly.
4. Settings and view results deep-link correctly.
5. Search documentation and public contracts match implementation.
