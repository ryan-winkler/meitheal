# Phase 14.4 Context: Upcoming Shell Rollout

## Domain Boundary

This phase applies the unified shell to `/upcoming` while extracting the legacy page scripts into a lifecycle-safe controller.

## Decisions

1. Keep Upcoming on one route with hash-linked shell sections for ingress safety.
2. Preserve grouped day accordions and quick completion instead of flattening the page into a generic list.
3. Keep Today and Calendar adjacency explicit in the page flow section.
4. Route task-detail handoff through the shared task detail surface.
