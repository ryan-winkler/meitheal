# Phase 14.3 Context: Today Shell Rollout

## Domain Boundary

This phase applies the mature unified shell to `/today` without redefining the Today domain model, Smart Today ranking logic, task APIs, or habit persistence.

## Decisions

1. Keep Today on the same route with hash-linked shell sections so the page remains ingress-safe.
2. Preserve the existing `today-controller.ts` feature set instead of replacing Smart Today behavior with a thinner page.
3. Keep `Clear Done` in the shell action cluster and `New Task` in the shared shell button.
4. Preserve task-detail handoff through the shared task detail surface.

## Deferred Ideas

1. Tier 2 ingress and companion closeout for the full phase family.
2. A wider event-listener cleanup across all historical Today controller paths.
