# Phase 14.5 Context: Calendar Shell Rollout

## Domain Boundary

This phase applies the unified shell to `/calendar` while preserving the month grid, HA sync, day drawer behavior, and the secondary task-view strip.

## Decisions

1. Keep `TaskViewTabs` directly beneath `UnifiedBar`.
2. Keep prev/next/today month controls inside the `calendar-month` section.
3. Keep `Sync` in the shell actions.
4. Preserve same-route shell anchors and query-preserving route-switch tabs.
