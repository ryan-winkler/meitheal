# 08.2-01: Settings Controller Decomposition

## Objective

Decompose `settings-controller.ts` (3,561 LoC) from a single monolithic function into 6 domain-aligned controller modules + shared utilities, while removing anti-patterns inline.

## Tasks

<task id="01" name="Create settings-utils.ts with shared utilities">
Extract `saveSetting()`, `loadSettings()`, and CSS sanitization constants (`DANGEROUS_CSS_PATTERNS`, `MAX_THEME_SIZE`, `sanitizeCSS`) from `settings-controller.ts` into a new `settings-utils.ts` shared module.
</task>

<task id="02" name="Extract theme controller" depends="01">
Create `settings-theme-controller.ts` with `initThemeSettings()`. Extract theme select, custom theme upload/apply/sanitize, `showCustomThemeSection()`, `updateCustomThemeDisplay()`. Map to lines ~86–220, ~703–910 of the monolith. Replace inline `.style.*` with CSS class toggles where applicable.
</task>

<task id="03" name="Extract sidebar controller" depends="01">
Create `settings-sidebar-controller.ts` with `initSidebarSettings()`. Extract sidebar ordering (drag/drop + touch), custom links, visibility toggles, save/reset handlers. Map to lines ~258–798 of the monolith. Replace `window.location.reload()` after sidebar save/reset with `settingsStore.invalidate()` + DOM update.
</task>

<task id="04" name="Extract data/export controller" depends="01">
Create `settings-data-controller.ts` with `initDataSettings()`. Extract JSON export, SQLite download, settings import, custom fields CRUD. Map to lines ~1–85, ~800–850. Replace `window.location.reload()` after import with `settingsStore.invalidate()` + targeted DOM refresh.
</task>

<task id="05" name="Extract integrations controller" depends="01">
Create `settings-integrations-controller.ts` with `initIntegrationSettings()`. Extract HA connection test, calendar hydration, todo hydration, Grocy status, n8n diagnostics, Node-RED deploy, webhooks, HA Bus events. Map to lines ~620–2900+. Remove raw `fetch()` with manual ingress prefix where Layout monkey-patch handles it.
</task>

<task id="06" name="Extract AI/agents controller" depends="01">
Create `settings-ai-controller.ts` with `initAISettings()`. Extract AI provider select, conversation agent, protocol toggles, protocol save. Map to lines ~908–1050.
</task>

<task id="07" name="Extract danger zone controller" depends="01">
Create `settings-danger-controller.ts` with `initDangerZoneSettings()`. Extract purge all tasks, reset settings, factory reset. Map to lines ~3300–3400. Replace remaining `window.location.reload()` calls.
</task>

<task id="08" name="Slim settings-controller.ts to orchestrator" depends="02,03,04,05,06,07">
Reduce `settings-controller.ts` to a thin orchestrator (~100 LoC) that imports and calls all sub-controllers. Preserve the `initSettingsController()` export signature. Remove `loadSettings()` call from orchestrator — each sub-controller loads its own settings via `settings-utils.ts`.
</task>

<task id="09" name="Verify build and existing tests" depends="08">
Run `pnpm check` for typecheck, `pnpm build` in `apps/web/`, and existing e2e tests against local dev server. All must pass with zero regressions.
</task>
