# First-time setup

Open **Set up Meitheal** from Dashboard. Use **Simple** for Dashboard, Kanban, the Household task list, and Quick Add. Choose a theme on the same screen. **Follow system** follows the device's light or dark preference. If you already use a named or custom theme, **Keep current theme** preserves it. An active Home Assistant appearance match still controls the visible palette.

Use **Advanced** to choose which page opens first and whether the regular New Task action opens Quick Add or the full form. The Board guide explains how Boards, Areas, Projects, Epics, tasks and Routines relate. **View permissions** describes the roles that govern your work. Open Boards for current access and Board Settings.

**Achievements**, **AI Setup**, and **Framework Scoring** take you to their existing Settings editors. Shared changes there follow your Home Assistant permissions. Advanced also links to more themes in Look & Feel.

**Skip setup** asks once before you leave. You can return through **Settings → Run setup again**. The appearance override, first page, capture choice and setup acknowledgement are stored in this browser for your verified Home Assistant sign-in. Standalone preferences apply to this browser. Existing Board settings and other members’ preferences are unaffected.

A bare app launch uses the first-page preference after Home Assistant has had a chance to restore the previous page. Explicit Dashboard links, bookmarks with a view or section, and links to a task keep their destination. Quick Add opens the full task form when you choose **Open full task form**. Board and project capture keep their existing task form and context.

## Troubleshoot

- If the browser cannot save choices, allow site storage and try again, or continue to Dashboard. Changing browsers requires configuring the browser again.
- If Board access cannot be checked, open Boards when Home Assistant is connected. The wizard displays only roles returned for the current account.
- If you cannot confirm a Quick Add save, keep the draft visible and check the task list before adding it again.
- A Board creation can save before the directory appears. When the form reports pending or unknown access, refresh Boards to check the result before repeating the action.
