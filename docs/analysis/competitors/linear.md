# Linear

**Verified from official docs (2026-03-15):** filter operators/templates in issue views.

## Search-Relevant Characteristics

1. Users can compose rich issue filters with operators like `is`, `neq`, `lt`, `lte`, `gt`, `gte`, and `contains`.
2. Filter templates can be saved and reused.
3. Search/navigation is treated as part of the command experience, not as a one-off text box.

## What Meitheal Should Borrow

1. Saved filter discoverability from the main search surface.
2. Richer search scopes instead of title-only lookup.
3. Clear separation between reusable query state and view rendering.
