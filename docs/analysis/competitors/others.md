# Additional Competitors

The repo also references Asana, TickTick, Vikunja, and Super Productivity in parity discussions. Search-specific official material for those products was not strong enough in this pass to justify precise capability claims in canonical docs.

## Decision

1. Use Teamhood, Linear, ClickUp, Jira, and Todoist as the verified search baseline for implementation.
2. Track the remaining competitor docs as follow-up documentation work rather than inventing details.
