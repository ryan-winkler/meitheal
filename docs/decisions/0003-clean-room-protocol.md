# ADR 0003: Clean-Room Protocol

## Status
Accepted

## Date
2026-02-28

## Decision

Use published interface documentation to design compatible behavior. Keep outside code and assets under their own terms with their attribution. The historical compatibility implementation is maintained separately from this release.
