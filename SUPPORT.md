# Meitheal support

Use the [public issue tracker](https://github.com/ryan-winkler/meitheal-ha-addon/issues) for install problems and product feedback. Use the [source repository’s issue tracker](https://github.com/ryan-winkler/meitheal/issues) for source changes.

- For a failed install, include the add-on name, version, device architecture, and the first error in the Supervisor log.
- For a task or routine problem, describe the last time it happened. Include what you tried and what you did next.
- For incorrect instructions, link to the guide and name the first step you could not finish.

Remove credentials, private addresses, and household details from reports. Use the [security policy](SECURITY.md) for a suspected vulnerability.
