# Automation and AI in Meitheal

Meitheal helps people plan household work in Home Assistant. Use automation to help with that work. Keep people in control of what the app reads and changes.

## Use a Meitheal installation

Create a token for each tool or integration. Grant the permissions it needs for its task. Keep tokens out of examples, logs, and reports.

Use sample tasks when you test a connection. Ask the installation owner before you send task details or household data to an external service.

| Job | Start here |
| --- | --- |
| Check that the app is running | `GET /api/health` |
| Read or update a task | [API and automation guide](docs/kcs/agent-automation-guide.md) |
| Connect an agent to Meitheal | [Agent guide](WEBMCP.md) |
| Connect an automation to task events | [Webhook setup](docs/kcs/webhook-setup-guide.md) |
| Report a security problem | [Private reporting](SECURITY.md) |
