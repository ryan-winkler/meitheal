# Business use and distribution

You can run Meitheal inside your organisation for your own work. The [Meitheal source license](LICENSE) covers this release.

| Use | Terms for Meitheal-owned code |
| --- | --- |
| Use Meitheal in your own business operations | Permitted |
| Publish an attributed fork or distribute a copy for free | Permitted with the notices and source required by the license |
| Sell copies, charge for access, or sell Meitheal-specific services | Prohibited under this license |
| Use a modified build inside your organisation | Offer the changes to the maintainer within 30 days of first operational use |
| Distribute or give others access to a modified build sooner | Offer the changes by that date |

See the [license](LICENSE) for the full grant and conditions. See [Contributing](CONTRIBUTING.md) for how to offer changes. Use [private reporting](SECURITY.md) for a security-sensitive change.

[Notices](NOTICE) lists separately licensed material. The compatibility API is outside this release and retains its existing license. Earlier add-on images have their own [distribution terms](https://github.com/Coolock-Village/meitheal-ha-addon/blob/main/LICENSE).
